# ساعت کاری

اپلیکیشن شخصی فارسی و راست‌به‌چپ برای ثبت ورود و خروج، تقویم شمسی، گزارش روزانه/هفتگی/ماهانه/فصلی، محاسبه حقوق و خروجی JSON. داده‌ها فقط روی دستگاه و در IndexedDB ذخیره می‌شوند؛ حساب کاربری، بک‌اند و ارتباط با سرور وجود ندارد. رابط فقط روشن است.

## نصب و اجرا

Node.js نسخه **۲۰٫۱۹ یا بالاتر** (یا ۲۲٫۱۲ به بالا) و npm نیاز است. نسخه‌های دقیق وابستگی‌ها در `package-lock.json` قفل شده‌اند.

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

روی رایانه عادی Vite آدرس محلی را اعلام می‌کند. اگر محیط اجرای محدود از تشخیص شبکه پشتیبانی نمی‌کند:

```sh
npm run dev -- --host 127.0.0.1
npm run preview -- --host 127.0.0.1
```

نصب وابستگی‌ها اینترنت نیاز دارد؛ پس از اولین بارگذاری نسخه production و تکمیل Service Worker، برنامه بدون اینترنت قابل استفاده است. نوتیفیکیشن و آفلاین را روی **build / preview** یا HTTPS آزمایش کنید؛ Service Worker در حالت توسعه فعال نیست. `npm run icons` آیکون‌های PNG و SVG را بازتولید می‌کند؛ فایل‌های آماده در سورس وجود دارند.

## معماری

- React + Vite، JavaScript، HashRouter، فونت محلی Vazirmatn.
- Tailwind CSS **v4** با افزونه `@tailwindcss/vite` و CSS-first در `src/styles/index.css`؛ بدون پیکربندی Tailwind v3 و PostCSS.
- Redux Toolkit شامل sliceهای settings، entries، holidays، dayNotes و ui. فایل‌های store، thunks، slices و selectors جدا هستند.
- هر تغییر ابتدا با thunk در Dexie ثبت می‌شود؛ پس از موفقیت ذخیره‌سازی، Redux به‌روز می‌شود. ثبت بازه‌ها داخل transaction اعتبارسنجی می‌شود تا ثبت هم‌زمان بازه‌های متناقض ایجاد نکند.
- `src/lib/calc.js`، `salary.js`، `validation.js` و `reminders.js` مستقل و خالص هستند. ساعت زنده در hook محلی است؛ در Redux نگهداری نمی‌شود.
- `src/sw.js` با injectManifest، precache تمام فایل‌های برنامه، مدیریت آپدیت و یادآوری‌ها را انجام می‌دهد. فونت CDN و API خارجی در زمان اجرا نداریم.

## استفاده

اولین اجرا چهار مرحله دارد: ساعت کار/نهار، حقوق، مجوز یادآوری، نصب. می‌توان مراحل را رد کرد و از تنظیمات دوباره اجرا کرد. همه یادآوری‌ها پیش‌فرض خاموش‌اند؛ دریافت مجوز به‌تنهایی آن‌ها را روشن نمی‌کند.

روی داشبورد «ثبت ورود الان» یک بازه باز می‌سازد و «ثبت خروج الان» همان بازه را می‌بندد. «ثبت با ساعت دلخواه» همیشه کنار آن است؛ ورود یا خروج با ساعت گذشته و افزودن بازه کامل را پشتیبانی می‌کند. تاریخ را در انتخاب‌گر دست‌ساز شمسی انتخاب کنید. زمان آینده، خروج برابر/قبل از ورود و هم‌پوشانی رد می‌شود. در همان روز تنها یک بازه باز مجاز است؛ روزهای دیگر می‌توانند بازه ناقص داشته باشند.

بازه باز امروز تا دقیقه جاری به‌صورت زنده محاسبه می‌شود؛ بازه باز گذشته **صفر دقیقه** است و با «تکمیل خروج» اصلاح می‌شود. بازه‌های بسته همان روز همچنان در جمع حساب می‌شوند. ساعت نهار از کارکرد کم نمی‌شود. در تقویم روز را انتخاب کنید تا بازه‌ها و یادداشت را تغییر دهید. حذف بازه تأیید دارد و Toast «برگردان» به مدت هفت ثانیه نمایش داده می‌شود.

مناسبت‌های دستی از تنظیمات افزوده یا ویرایش می‌شوند؛ هیچ تعطیلی رسمی از پیش وارد نشده است. یک مناسبت در هر تاریخ ذخیره می‌شود. تغییر تاریخ مناسبت به‌صورت اتمی رکورد قبلی را جایگزین می‌کند؛ اگر مقصد مناسبت دیگری داشته باشد، خطا نمایش داده می‌شود.

گزارش‌ها چهار فیلتر دارند. فایل JSON فیلتر فعال با Blob و UTF-8 دانلود می‌شود. تاریخ خروجی شمسی، تاریخ ذخیره‌سازی ISO میلادی و ساعت ذخیره‌سازی ۲۴ساعته است. حقوق در خروجی ماهانه و جمع سه ماه در خروجی فصلی می‌آید. **بازگردانی/Import در این نسخه وجود ندارد**؛ JSON برای نگه‌داری و تحلیل بیرونی است.

## GitHub Pages

سورس داخل این پوشه را در ریشه ریپوی خود قرار دهید، نه در یک پوشه اضافی داخل ریپو. در Settings → Pages، گزینه **Source: GitHub Actions** را انتخاب کنید. workflow موجود روی push به `main` یا اجرای دستی، `npm ci`، تست، build و استقرار پوشه dist را انجام می‌دهد؛ مجوزهای Pages و OIDC و concurrency تنظیم شده‌اند.

`BASE_PATH` در workflow به نام ریپو تنظیم می‌شود؛ نیازی به تغییر دستی نام ریپو در کد ندارید. `manifest`، scope، start_url، آیکون‌ها، SW و فونت با همان زیرمسیر ساخته می‌شوند. مسیریابی hash باعث می‌شود رفرش صفحات ۴۰۴ ندهد. نمونه build دستی برای زیرمسیر:

```sh
BASE_PATH=/my-repository/ npm run build
```

برای دامنه اختصاصی در ریشه، base برابر `/` بگذارید. تغییر دامنه یا مسیر می‌تواند محدوده ذخیره‌سازی یا نصب برنامه را تغییر دهد؛ JSON را پیش از جابه‌جایی نگه دارید. داده‌های چند نصب روی یک origin به دیتابیس هم‌نام دسترسی دارند؛ نام DB برای یک اپ شخصی ثابت انتخاب شده است.

## نصب روی اندروید و آفلاین

در Chrome سایت HTTPS را باز کنید، اجازه دهید یک بار کامل بارگذاری شود، سپس از تنظیمات برنامه «نصب برنامه» را بزنید. اگر مرورگر دکمه نصب ارائه نکرد، منوی سه‌نقطه ← نصب برنامه / افزودن به صفحه اصلی را استفاده کنید. پس از آماده‌شدن نسخه جدید، بنر «نسخه جدید آماده است، به‌روزرسانی» ظاهر می‌شود؛ آپدیت SW داده Dexie را پاک نمی‌کند.

در پایان onboarding یک بار درخواست `navigator.storage.persist()` داده می‌شود. نتیجه در تنظیمات نمایش داده می‌شود و می‌توان درخواست را تکرار کرد. قبول این درخواست در اختیار مرورگر است و جایگزین نگه‌داری خروجی JSON نیست.

## یادآوری‌ها و محدودیت‌ها

نمایش با `registration.showNotification()` انجام می‌شود، نه `new Notification()`؛ بدون Web Push، سرور یا تایمر زمان‌بندی بومی. تابع خالص `checkReminders()` هم در صفحه برای بنر و هم در SW برای تصمیم ارسال استفاده می‌شود. SW مستقیم Dexie را می‌خواند. کلید تاریخ/نوع در notifyLog پس از ارسال ذخیره می‌شود؛ پیام‌ها tag یکسان دارند و درخواست‌های صفحه و Periodic Sync در SW پشت سر هم پردازش می‌شوند.

سه محرک: هر ۳۰ ثانیه وقتی برنامه اجراست، رویداد Periodic Background Sync با درخواست فاصله حداقل ۱۵ دقیقه در مرورگر پشتیبان، و بازشدن/visibleشدن برنامه. زمان و حتی اجرا در پس‌زمینه بسته کاملاً در اختیار مرورگر است. **ارسال هنگام بسته‌بودن برنامه یا پس از ریستارت گوشی تضمین نمی‌شود**. محدودیت باتری/سیستم ممکن است تایمر صفحه و Periodic Sync را متوقف کند. موعد بسیار قدیمی به‌صورت اعلان ارسال نمی‌شود و هنگام بازشدن بنر ظاهر می‌شود. با مجوز blocked باید از تنظیمات سایت Chrome اجازه را دستی عوض کنید. برنامه را از بهینه‌سازی باتری مستثنی کنید.

کلیک روی یادآوری خروج/بازه باز مسیر `#/?manual=out` را باز می‌کند؛ نزدیک‌ترین بازه باز (جدیدترین روز) برای خروج انتخاب می‌شود. تگ برنامه صحیح با base ساخته می‌شود. درخواست مجوز فقط با دکمه کاربر انجام می‌شود.

## آزمون‌ها و وضعیت بررسی

`npm test` شامل جمع بازه‌ها، بازه باز امروز/گذشته، تعطیلی، اضافه/کسر/تأخیر/تعجیل، حقوق و پیش‌بینی، تبدیل جلالی و کبیسه، هم‌پوشانی و ثبت دستی، ساخت JSON، reminder window/duplicate، hydrate و CRUD/Undo/transactionهای Dexie با fake-indexeddb و reducer/selectorهاست. تست DOM صفحات با jsdom مسیرهای onboarding، ثبت سریع و دستی، جابه‌جایی صفحات و فیلترها را بررسی می‌کند؛ نمودار و قابلیت‌های بومی مرورگر در این تست جایگزین دارند و این تست **تست مرورگر واقعی نیست**.

در محیط ساخت `npm install`، `npm test` و `npm run build` اجرا شدند. build زیرمسیر `/test-repository/` و مسیر ریشه هر دو موفق بودند؛ manifest، مسیر دارایی‌ها و وجود SW بررسی شدند. آخرین اجرای تست: **۳۹ تست در ۸ فایل، همه موفق**. نسخه اولیه Vitest ۳ در این محیط پس از اجرا متوقف می‌ماند؛ Vitest ۴ انتخاب شد و suite بدون توقف کامل می‌شود.

بررسی تصویری و مرورگر واقعی در محیط ساخت ممکن نشد: مرورگر ابری به localhost دسترسی نداشت و Chromium محلی با محدودیت سیستم اجرا نشد. **عدم خطای کنسول واقعی، انطباق تصویری، ریسپانسیو و آفلاین عملی ادعا نشده‌اند.** طرح اولیه فقط مرجع پالت روشن، تایپوگرافی فارسی، ساختار کارت‌ها، دکمه‌های مجاور و نوار پایین بوده است. اختلاف عمدی: دکمه ورود مطابق الزام سبز است؛ داده‌ها و تاریخ و هدف از تنظیمات واقعی می‌آیند؛ بلوک‌های الزامی اطلاعات روز/حقوق نیز اضافه شده‌اند.

## تست دستی — انجام‌نشده روی دستگاه واقعی

همه موارد زیر باید پیش از اتکا به نسخه روی گوشی تیک بخورند؛ تولید کد یا عبور unit test به معنی عبور این موارد نیست.

- [ ] نصب روی اندروید و بازشدن standalone.
- [ ] مرور همه صفحات روی موبایل، تبلت و دسکتاپ؛ RTL، کنتراست، فوکوس، لمس و نبود overflow.
- [ ] اجرای برنامه آفلاین در حالت هواپیما پس از precache کامل؛ فونت و آیکون‌ها آفلاین.
- [ ] ثبت ورود/خروج‌های متعدد و ویرایش/حذف/Undo از رابط واقعی.
- [ ] انتخاب تاریخ کبیسه، جابه‌جایی ماه و فصل و کلیک تقویم.
- [ ] ثبت دستی گذشته، بستن بازه ناقص و رد ساعت آینده یا هم‌پوشانی از رابط واقعی.
- [ ] یادداشت و تعطیلات دستی و تأثیرشان بر حقوق/موظف.
- [ ] دانلود واقعی JSON هر چهار فیلتر و نام/UTF-8 آن در Chrome اندروید.
- [ ] مجوز نوتیفیکیشن در حالت default، granted و denied؛ درخواست فقط با اقدام کاربر.
- [ ] نوتیفیکیشن آزمایشی از تنظیمات.
- [ ] یادآوری با برنامه باز، پس‌زمینه و بسته (پشتیبانی مرورگر/عدم تضمین).
- [ ] رفتار یادآوری پس از ریستارت گوشی.
- [ ] کلیک خروج/هشدار و بازشدن مستقیم شیت خروج؛ از حالت باز و بسته.
- [ ] عدم تکرار اعلان در تحریک هم‌زمان صفحه و پس‌زمینه.
- [ ] آپدیت به نسخه جدید و حفظ داده‌ها.
- [ ] رفتار با بهینه‌سازی باتری فعال و غیرفعال.
- [ ] ذخیره‌سازی پایدار و نمایش نتیجه واقعی مرورگر.
- [ ] پاک‌سازی دو مرحله‌ای فقط با داده آزمایشی خود کاربر.
- [ ] استقرار واقعی GitHub Pages و رفرش hash route و نبود خطای کنسول.

پاک‌کردن داده مرورگر، حذف اطلاعات سایت، تغییر origin یا سیاست پاک‌سازی مرورگر ممکن است داده‌ها را حذف کند. ZIP سورس است و داده کاربر را در خود ندارد.

## فاز بعد

بازگردانی از JSON، همراه اعتبارسنجی نسخه، پیش‌نمایش و مدیریت تعارض. این قابلیت در نسخه فعلی عمداً ساخته نشده است.

## محتویات تحویل

ZIP شامل سورس، آیکون‌ها، اسکریپت بازتولید آیکون، تست‌ها، lockfile و workflow است؛ `node_modules` و `dist` و فایل‌های موقت QA در ZIP نیستند. build را با دستور بالا بسازید.
